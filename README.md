# Miller OOH — Curitiba

Aplicação de acompanhamento de pontos de captação da campanha Miller OOH em Curitiba.

## Aplicação

O painel está em `src/index.html` e é servido como site estático pela Vercel. O arquivo de entrada deve permanecer nesse caminho enquanto o projeto Vercel estiver configurado para publicar a pasta `src`.
