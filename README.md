# Miller OOH — Curitiba

Aplicação de acompanhamento dos pontos de captação da campanha Miller OOH em Curitiba.

## Estrutura

- `src/index.html`: painel web, com mapa, filtros, indicadores e acesso da equipe.
- `src/assets/`: logotipos e título gráfico usados no cabeçalho.

## Configuração Vercel

O projeto deve usar `src` como **Root Directory**. É um site estático, sem etapa de build. Manter os assets dentro de `src/assets` garante que sejam servidos em `/assets/...`.
